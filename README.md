# Strong Performance | Centro Automotivo

Site institucional desenvolvido para a Strong Performance Centro Automotivo, com o objetivo de fortalecer a presença digital da empresa, apresentar seus serviços e facilitar o contato com clientes.

O projeto combina design moderno, recursos interativos e experiências visuais em 3D, proporcionando uma navegação mais dinâmica e uma apresentação diferenciada dos serviços automotivos.

## 🌐 Demonstração

**Acesse o site:** https://www.strongperformance.com.br/

**Repositório:** https://github.com/EdmarAraujoDev/strong-performance-site

## 🚀 Funcionalidades

- Apresentação institucional da empresa.
- Layout responsivo para diferentes dispositivos.
- Exibição dos serviços automotivos.
- Experiência visual interativa com modelos 3D de veículos.
- Personalização de cores da pintura do veículo.
- Animações e efeitos durante a navegação.
- Galeria de imagens da oficina.
- Seção de depoimentos.
- Integração com Google Maps.
- Botões de contato e orçamento via WhatsApp.
- Informações de localização e atendimento.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** interatividade e funcionalidades.
- **Three.js:** renderização de modelos tridimensionais.
- **GSAP:** animações e transições.
- **GSAP ScrollTrigger:** animações associadas à rolagem da página.
- **Font Awesome:** biblioteca de ícones.

## 🎨 Experiência visual

Um dos diferenciais do projeto é a utilização de modelos tridimensionais de veículos, permitindo uma experiência visual mais imersiva.

A interface foi desenvolvida para combinar identidade visual, apresentação dos serviços e recursos interativos, mantendo o foco na experiência do usuário.

## 💻 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/EdmarAraujoDev/strong-performance-site.git
```

2. Entre na pasta:

```bash
cd strong-performance-site
```

3. Abra o projeto utilizando o VS Code.

4. Execute o arquivo `index.html` com a extensão Live Server para visualizar a aplicação localmente.
